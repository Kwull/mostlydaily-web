Warum ein verpasster Tag deiner Gewohnheit nicht schadet

Ein verpasster Tag fühlt sich wie ein Scheitern an, wenn eine App zeigt, wie eine Serie auf null zurückgeht. Er ist keins.

Gewohnheiten entstehen durch Wiederholung über Wochen und Monate. Eine einzelne Lücke in dieser Wiederholung ändert das Muster kaum: Die Gewohnheit bleibt das, was du in diesem Moment, an diesem Ort, nach diesem Auslöser ganz von selbst tust. Das Muster ändert sich, wenn aus einem Aussetzer zwei werden, dann drei, und der Auslöser nicht mehr zur Handlung führt.

Auf den Tag danach kommt es an

Deshalb heißt der Lauf in Mostly Daily "Nie zweimal in Folge verpasst". Ein Aussetzer lässt den Lauf weitergehen. Zwei Aussetzer in Folge beenden ihn, ganz sanft, und mit deinem nächsten Check-in beginnt ein neuer. Nach einem verpassten Tag lautet die Frage: "Was ist das Kleinste, das ich heute tun kann?"

Lass die kleinste Version zählen

Jede Gewohnheit kann eine Zwei-Minuten-Version haben: eine Seite lesen, die Schuhe anziehen, einen Zahn mit Zahnseide reinigen. An einem vollen Tag zählt sie genauso viel. Sie hält Auslöser und Handlung zusammen.

Beständigkeit zählt

Jede Gewohnheit hat eine Stufe, die auf den letzten paar Monaten beruht. Ein Aussetzer nach einem guten Monat kostet ein paar Punkte; du bist weiterhin bei Meistens. Die Stufe steigt so schnell wieder, wie sie gesunken ist. Du brauchst nie 100 %.
